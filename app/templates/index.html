How It Works

1. Register

Create your account with email and a secure password. Your data is protected with bcrypt hashing.

2. Authenticate

Sign in to receive a secure JWT token stored in httpOnly cookies for maximum security.

3. Build

Use the included Item model as a template to build your own features with full CRUD support.

Tech Stack

Backend

FastAPI + SQLModel + SQLite

Frontend

Jinja2 + HTMX + Pico CSS

Auth

JWT + bcrypt + CSRF
